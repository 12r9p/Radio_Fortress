# Radio Fortress 📡

macOSメニューバーにWiFi通信品質の**擬似コンスタレーション・ダイアグラム**を表示するユーティリティアプリ。

## 概要

WiFiの変調方式（BPSK / QPSK / 16-QAM / 64-QAM / 256-QAM）に応じた信号点をI-Q平面上にプロットし、SNR（信号対雑音比）に基づくジッター（揺れ）とデータ伝送レートに連動した発光エフェクトで、通信品質をリアルタイムに可視化します。

## 動作環境

- macOS 13.0 (Ventura) 以降
- Xcode 15.0 以降
- WiFi接続環境

## セットアップ

### 1. XcodeGen のインストール

```bash
brew install xcodegen
```

### 2. Xcodeプロジェクトの生成

```bash
cd Radio_Fortress
xcodegen generate
```

### 3. ビルドと実行

```bash
open RadioFortress.xcodeproj
```

Xcode上で `Cmd + R` でビルド＆実行。

## 使い方

1. 起動するとメニューバーに小さなコンスタレーション風アイコンが表示されます
2. アイコンをクリックするとポップオーバーが開き、詳細なコンスタレーション・ダイアグラムとWiFi情報が表示されます
3. アプリはDockに表示されません（メニューバー専用アプリ）

## 表示内容

| WiFi品質 | 変調方式 | ポイント数 | 視覚的特徴 |
|:---------|:---------|:-----------|:-----------|
| 最良 | 256-QAM+ | 256点 | 点が格子状にピシっと静止、緑色 |
| 良好 | 64-QAM | 64点 | 微小なジッター、シアン色 |
| 普通 | 16-QAM | 16点 | 中程度のジッター、黄色 |
| 劣悪 | BPSK/QPSK | 2-4点 | 大きくブルブルと震える、赤色 |

## 技術スタック

- **SwiftUI** - MenuBarExtra / Canvas描画
- **CoreWLAN** - WiFi接続情報の取得
- **Core Graphics** - メニューバーアイコンの動的レンダリング
